# Atelier — Управление магазином

## Описание

Приложение для управления ассортиментом магазина.

Используются:
- Python
- CustomTkinter
- SQLite
- Pillow

## Возможности

- Просмотр каталога товаров.
- Добавление товаров.
- Изменение цены и количества.
- Удаление товаров.
- Поиск по названию.
- Просмотр статистики.
- Автоматическое создание базы данных.
- Проверка пользовательского ввода.
- Тёмная пастельная тема.

## Установка

Создание виртуального окружения:

    py -m venv .venv

Активация окружения в Windows:

    .venv\Scripts\activate

Установка зависимостей:

    python -m pip install -r requirements.txt

Запуск:

    python app.py

## База данных

При первом запуске автоматически создаётся файл shop.db.

Таблица products содержит:
- id
- name
- price
- quantity
